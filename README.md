# AARAMBH-Manager

Akshara enterprises employee and mentor management portal.

## Features
- Dynamic dashboards for Super Admin, Admin, Mentor, and Employee roles.
- Interactive onboarding tracking and lesson systems.
- Team management, accountability chains, and metrics reporting.
- Advanced search and filtering on mentors and employees.
- Performance dashboards and daily status tracking.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
